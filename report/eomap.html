EO board register map (decoded)

The EO board's register space is built from five identical "ramp controller" chips. The GSP module (g200.440) describes them with five structures, _CHIP0…_CHIP4, filled by _init_ramp_controller_struct. Chip n sits at register base n·0x20. The layout within each chip comes from _set_ramp / _disable_ramp. The output assignments come from tracing every _write_EO_value / _read_EO_value call in g200.440 and every remote write in the DSP firmware.
