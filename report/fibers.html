The four EO fibers (confirmed hardware)

Your photo of the EO board shows one HFBR-1521 transmitter (grey) and three HFBR-2521 receivers (blue), all HP/Agilent Versatile Link parts rated at 5 MBd. So three fibers run IP board → EO board and one runs EO → IP. The return fiber explains the busy-flag handshake and the register readback in the DSP code. The 5 MBd rating caps every signal on these fibers. A 5 MBd capture front-end (any logic analyser at ≥25 MS/s) is enough, and no pixel clock above about 5 MHz can be on them.

Capture decoding guide

Each register write should appear as one packet carrying a target (EO or HRRU), a 10-bit register number and a 16-bit value, followed by an acknowledge on the return fiber. A read sends the address and gets the value back on the return fiber. These UI actions should each produce a short, recognisable set of writes:
